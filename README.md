# Vids for RS

Projet de création de **vidéos courtes d'information sur l'IA** pour les réseaux sociaux
(TikTok, Instagram Reels, YouTube Shorts…) : actus, annonces et articles de blog
des grands acteurs du domaine (Anthropic, OpenAI, Google DeepMind, Meta, Mistral…).

## Objectifs

1. **Informer** : rendre l'actualité IA claire, sourcée et utile en moins de 90 secondes.
2. **Fidéliser** : une identité forte (design system, mascotte, rituels) pour que les
   viewers reconnaissent les vidéos au premier coup d'œil, s'abonnent et reviennent.
3. **Automatiser** : à terme, **une session Claude = une vidéo**. On fournit un article,
   Claude produit la vidéo prête à publier + description + hashtags.
