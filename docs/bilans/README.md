# Bilans hebdomadaires

Un fichier par lundi (`AAAA-MM-JJ.md`), écrit par le skill `bilan`.

Pour croiser les chiffres déjà relevés sans appeler Postiz : `npm run bilan -- --local`
(`--age-min 24` écarte les posts trop récents). Il donne des médianes, le nombre de posts
de chaque case et, par réseau, combien de posts il faut par groupe pour voir un effet. Les
commentaires y sont ceux du public : notre commentaire de sources est retiré (Instagram,
Threads, LinkedIn). Une case de moins de 5 posts n'est pas une preuve. Exemple de lecture :
`analyse-metriques-2026-11-09.md`.
