## Fiche

### Faits
- OpenAI a conclu un accord pour acquérir The Pierre Computer Company, Inc. (« Pierre »), entreprise spécialisée dans l'infrastructure de stockage de code et les outils de développement pour le travail machine et les agents d'IA.
- Pierre a été cofondée en 2023 par Jacob Thornton (co-créateur du framework Bootstrap chez Twitter) et Ian Ownbey (ancien ingénieur chez Twitter et Coinbase).
- Le produit phare de la startup est Code Storage, une couche de stockage de dépôts Git distribuée, compatible Git et pilotée par API, optimisée pour absorber les flux de travail à fort volume et en parallèle exécutés par des agents d'IA.
- Pierre a développé plusieurs bibliothèques et outils open source réputés : Trees (navigation ultrarapide dans l'arborescence des fichiers d'un projet), Diffs (visualisation des modifications de code dotée d'un mode édition interactive permettant de corriger des bugs directement dans la vue différentielle) et Highlights (moteur de coloration syntaxique en temps réel pendant la saisie humaine ou le streaming de code par l'IA).
- OpenAI utilise déjà directement les bibliothèques open source Trees et Diffs de Pierre au sein de son application Codex pour la navigation de projet et la revue des modifications.
- L'acquisition vise à intégrer nativement la technologie Code Storage et l'équipe d'ingénieurs de Pierre au cœur de la plateforme Codex.
- OpenAI entend combiner les outils de Pierre avec Pando, son backend Git interne optimisé pour le travail simultané de milliers d'agents, afin d'adapter les flux Git traditionnels à la production continue de code par l'IA.
- Cette acquisition positionne Codex comme un environnement complet de gestion de dépôts, de collaboration et d'historique de code, concurrençant plus frontalement les plateformes de développement comme GitHub (Microsoft).
- OpenAI s'engage à maintenir les projets open source existants de Pierre sous licence open source et à poursuivre ses contributions actives à ces briques.
- Les clients actuels du service Code Storage continueront d'être pris en charge et accompagnés pendant l'intégration progressive de la technologie dans Codex.
- La transaction est soumise aux conditions de clôture usuelles et à l'approbation des autorités réglementaires.
- Jusqu'à la clôture officielle de l'opération, OpenAI et Pierre Computer Company continuent d'exercer leurs activités de manière totalement indépendante.
- Les conditions et détails financiers de la transaction ne sont pas divulgués.

## Texte de l'article

OpenAI to acquire Pierre Computer Company, Inc.

November 4, 2026 — 14:30 UTC

Today we’re announcing that OpenAI will acquire Pierre Computer Company, Inc. (“Pierre”), the company behind Code Storage and a family of standout open-source developer tools.

If you've browsed files or reviewed a change in the Codex app, you've already used Pierre's Trees and Diffs libraries. We're excited to work with the Pierre team to build on the Git workflows that developers already rely on and adapt them to how teams work with coding agents.

Pierre was founded in 2023 by Jacob Thornton and Ian Ownbey to build developer infrastructure designed for modern engineering workflows. The company created Code Storage, a scalable, API-driven Git repository storage layer optimized for machine workloads and parallel agent operations. Pierre also developed several widely adopted open-source tools: Trees, which enables lightning-fast navigation through project file trees; Diffs, which renders code modifications with an interactive Edit mode allowing developers to patch bugs directly in the diff view; and Highlights, a real-time syntax highlighting engine that updates as developers type or as AI agents stream code.

OpenAI plans to deeply integrate Pierre’s technology and team directly into Codex. By pairing Pierre's tools and Code Storage with OpenAI’s internal version control backend, Pando, we will expand Codex from a code-generating assistant into a comprehensive code collaboration and repository management platform capable of supporting autonomous agents writing code continuously at scale.

Pierre’s open-source projects will remain open source, and OpenAI will continue contributing to them. Existing Code Storage customers will continue to be supported as we integrate its capabilities into the Codex platform.

The transaction is subject to customary closing conditions, including the receipt of regulatory approvals. Until the transaction closes, the companies will continue to operate independently. Financial terms of the transaction were not disclosed.
