## Fiche

### Faits
- OpenAI a annoncé le 4 novembre 2026 le lancement d'Images 2.6, la nouvelle version de son générateur d'images.
- Images 2.6 introduit la génération de petites animations en boucle au format GIF directement dans l'interface de ChatGPT.
- La création de GIF fonctionne soit à partir d'une simple description textuelle (prompt), soit à partir d'une image fixe importée par l'utilisateur.
- OpenAI met principalement en avant trois cas d'usage : la création de mèmes, les réactions pour les réseaux sociaux et la conception de mascottes animées.
- En mode texte, l'utilisateur formule sa demande dans le chat en précisant l'action et le mouvement attendus (ex. : « Crée un GIF d'un chat rose qui danse »).
- En mode image, ChatGPT génère d'abord une image intermédiaire montrant le personnage décomposé dans différentes poses avant de produire le GIF final.
- Le test réalisé par la journaliste a permis d'animer un personnage protégé par le droit d'auteur (Tony Tony Chopper du manga One Piece) sans blocage des filtres, bien que le rendu fût moins naturel qu'avec une création originale.
- Une fois le GIF généré, l'utilisateur peut lui demander des retouches et modifications en langage naturel au fil de la conversation avant de le télécharger.
- ChatGPT est également capable d'éditer ou de ralentir un GIF existant en recevant directement son lien URL (testé avec succès sur le GIF d'un chat tapant sur un clavier).
- Selon OpenAI, l'outil peut concevoir une animation à partir d'un simple croquis ou dessin soumis dans la discussion.
- OpenAI annonce le déploiement d'Images 2.6 à l'échelle mondiale, sur toutes les formules de ChatGPT ainsi que sur Codex.
- Le centre d'aide d'OpenAI précise toutefois que la création de GIF fait l'objet d'un déploiement progressif et peut ne pas être immédiatement accessible sur tous les comptes.
- Selon OpenAI, Images 2.6 accélère la vitesse de génération des images de 50 % par rapport aux versions antérieures.
- Images 2.6 améliore la fidélité et la cohérence des détails visuels au cours des retouches itératives.
- ChatGPT introduit une fonction permettant d'enregistrer une image de référence sous un nom donné pour la rappeler ultérieurement dans une autre conversation via la mention « @ » (ex. réutiliser une photo de son animal de compagnie sans devoir la réimporter).

## Texte de l'article

ChatGPT peut maintenant créer vos GIF : voici comment animer vos images
Sous-titre : ChatGPT veut intégrer les réseaux sociaux

Un chat qui danse, un dessin qui prend vie ou une mascotte qui fait coucou : ChatGPT commence à générer des GIF à partir de vos instructions. La fonction accompagne l’arrivée d’Images 2.6, annoncée le 4 novembre 2026.

Si vous utilisez des GIF dans votre quotidien, bonne nouvelle : vous pourrez désormais créer le votre, via ChatGPT. OpenAI a annoncé le 4 novembre 2026 une nouvelle version de son générateur d’images, baptisée Images 2.6. Parmi les nouveautés, la possibilité de créer de petites animations en boucle à partir d’une description ou d’une image fixe.

Vous pouvez ainsi demander au chatbot d’inventer un personnage animé, mais aussi lui confier un dessin pour le faire bouger. OpenAI met notamment en avant la création de mèmes, de réactions pour les réseaux sociaux et de mascottes animées.

Comment créer un GIF avec ChatGPT ?

Comme l’explique la documentation d’OpenAI, il suffit de demander un GIF dans le chat en précisant ce qui doit bouger. Par exemple : « Crée un GIF d’un chat rose qui danse. » Pour partir de votre propre illustration, importez-la dans la conversation et décrivez le mouvement souhaité : « Fais moi un GIF dans lequel ce personnage danse. » ChatGPT va d’abord vous proposer une image dans laquelle on voit le personnage dans différents poses, avant de générer le GIF.

J’ai ainsi pu créer un GIF à partir d’une image de Tony Tony Chopper (One Piece). L’outil a accepté de l’animer malgré son appartenance à une œuvre protégée. Le résultat était toutefois moins naturel que pour le chat rose.

Une fois l’animation générée, vous pouvez demander des modifications dans la conversation, puis télécharger le GIF. J’ai également pu ralentir un GIF existant, celui du chat qui tape frénétiquement sur un clavier, simplement en fournissant son lien. Selon OpenAI, il est aussi possible de créer une animation à partir d’un simple croquis envoyé à ChatGPT.

Un déploiement encore en cours

OpenAI annonce Images 2.6 dans le monde entier, sur toutes les formules de ChatGPT et de Codex. Son centre d’aide précise toutefois que la création de GIF est en cours de déploiement : elle peut donc ne pas être immédiatement accessible sur votre compte.

Cette version doit aussi accélérer la génération d’images de 50 %, selon l’entreprise, et mieux conserver les détails au fil des retouches. ChatGPT permet par ailleurs d’enregistrer une photo de référence sous un nom, puis de la rappeler dans une autre conversation avec une mention précédée de @. Par exemple, pour réutiliser la photo de votre chien sans devoir la joindre à chaque nouvelle demande.
